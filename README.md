# PLACE · Equidade Social

Site da apresentação **“Moradia digna, saneamento e equidade social — o território como definidor de vida”**.

Participantes: Anna Clara Tourinho, Gabriele Nascimento, Maria Eduarda Souza Von Ah, Juliana Cerqueira, Nicole Sales, Evelyn de Jesus, Jonas Walner e Caroline Marques.

## Estrutura

```
index.html        → página principal
css/style.css     → estilos
js/script.js      → pesquisa, menu e animações
assets/           → logo e ícone
```

## Pesquisa

Clique em **Pesquisar** (ou aperte `/` ou `Ctrl/Cmd + K`). A busca ignora acentos e maiúsculas e aceita várias palavras.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie todos os arquivos desta pasta (o `index.html` precisa ficar na raiz).
2. No repositório, vá em **Settings → Pages**.
3. Em **Source**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)` e clique em **Save**.
4. Depois de 1–2 minutos o site estará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
